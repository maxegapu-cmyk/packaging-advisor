# 风格发想：先看产品再选，不要把这当硬模板

下列都是原创起点，颜色只是**灵感值**，不是被观察到的品牌色，也不是量产印刷色。选色要兼顾渠道、品类和真实品牌已有颜色，HEX 需依据实际调整。

| 气质 | 四色色卡（底/字/主视觉/点缀） | 构图抓手 | 避免 |
|---|---|---|---|
| 静谧陈列 | `#EEE9DC` / `#252D30` / `#607E77` / `#C18B54` | 大留白、非对称产品局部裁切 | 只留白而没有产品辨认 |
| 工业标识 | `#E7EAEC` / `#172630` / `#1D55B7` / `#E76D33` | 左侧索引条、粗体编号 | 字太多像维修手册 |
| 植物手作 | `#E7E8D7` / `#304B3C` / `#8E9C65` / `#C47D62` | 手绘局部、纸纹、疏密交替 | 泛滥的绿叶图库 |
| 色块玩味 | `#F5D94B` / `#292536` / `#D65361` / `#ECE5F2` | 大字压色块、错位关系 | 对比过强影响文字阅读 |
| 档案收藏 | `#F1EEE5` / `#242328` / `#9A4644` / `#A7A09B` | 档案编号、横向分隔、雕版感字形 | 假历史、假产地或假奖章 |
| 轻盈未来 | `#EAF4F2` / `#143C4B` / `#2F8D9C` / `#D0B8A5` | 极窄细线与大块几何留白 | 无意义光效和荧光渐变 |
| 夜色戏剧 | `#202329` / `#FAF0D9` / `#C44C41` / `#B8A48B` | 明暗反转、单色大图、侧边微标签 | 黑色一铺到底看不清层级 |
| 清爽实用 | `#F3F5F4` / `#163F47` / `#6EAE9A` / `#F1A25A` | 分栏网格、功能图示、简短大标题 | 过于像 SaaS 网站卡片 |

## 配色决定必须说清的四件事

1. **色彩职责**：背景负责干净，文字负责清晰，识别色负责记忆，强调色负责信息提醒。
2. **面积关系**：给一个大约分配，如底色65% / 字与结构25% / 主识别8% / 强调2%；这是*提案*，不是行业标准。
3. **情绪方向**：高饱和 + 大色块通常更外向，低饱和 + 高留白通常更平和，但也受图像和字体影响。
4. **色彩续航**：内袋用什么色？说明书封面和页码怎么复用？小尺寸下是否依然容易认？

字体选择建议先谈“字形性格”和“主副字对比”，不必强行指定商业字体；具体使用需核对字库授权、中文字符覆盖和打印清晰度。

## 产生显著差异的三组选择

- **信息结构**：标签化信息 vs. 海报化标题 vs. 画册化图片。
- **图像表现**：白底实物局部 vs. 单色影像 vs. 场景插画。
- **留白与密度**：疏散陈列 vs. 集中块面 vs. 节奏型重叠。

如果三个方案除了 HEX 一样，说明创意尚未完成。
