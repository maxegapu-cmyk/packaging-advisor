# 看图拆解：把参考图转成“可用的设计语言”

这张表只用于构思；如果没有看图能力，不要靠猜填空。

## 四类图不要混为一谈

- **产品图**：只判断品类、形状、材料外观、显著使用场景。看不到的规格不猜。
- **心仪参考**：只提炼阅读路径、色块覆盖、文字密度、图像呈现，不模仿独有图案、LOGO、文案。
- **旧版包装**：指出需要保留/强化/移除的视觉结构，而不是全盘推倒。
- **竞品**：找品类的共同“货架语言”，以及如何明显区别。

## 五个观察窗口

1. **三秒钟**：最先被看见的是字、物、插图还是色块？产品名是否能快速辨认？
2. **画面骨架**：轴线是居中、左齐、右齐、对角、网格、上下分区还是环绕？哪一块留白最大？
3. **颜色站位**：按大面积底色、承担可读性的字色、品牌强调色分层；只从可见颜色描述，不伪造精准吸色值。能提取像素时才给提取值，其他是近似提案。
4. **字与图关系**：字是主角还是说明；摄影占比、剪裁、插画密度、纹理强度如何？
5. **跨载体潜力**：这个元素是否还能放进窄侧面、内袋、说明书页眉？能缩小吗？

## 最小输出

> 图片2：第一眼落在左上角的大字，右下角是局部产品裁切；底色宽松、字体占比高。适合借鉴“偏置大字 + 单一产品局部图”的结构；不建议复刻其原品牌徽记与独家图案。用于我们的内袋时可以只保留大字截角。

如果多张参考互相冲突：指出冲突（如 A 极简，B 重插画），再做两个层级选择：品牌核心承袭哪张，局部表现引用哪张。不要“全部融合”成大杂烩。

## 反馈词翻译成操作

| 用户说 | 优先查 | 默认修法 |
|---|---|---|
| 太普通 | 焦点是否缺席，包装是否一眼像通用模板 | 加一个产品相关而非纯装饰的识别锚点 |
| 太花 | 高饱和色和图案是否同时争焦点 | 只保留一个最强元素，缩小装饰面积 |
| 看不懂是什么产品 | 产品名是否被风格压过 | 将品类词提高到第二层级，在正面显著呈现 |
| 配色怪 | 冷暖冲突、文本对比低、强调色太多 | 重新分配色彩功能与面积，优先改占比 |
| 像别人家 | 字体 + 构图 + 图片处理三者重合 | 优先换独特图形结构与版式，不只改HEX |
| 说明书像另一个品牌 | 说明书丢了外包装的识别元素 | 沿用同一章节色、图形锚点和标题节奏 |
