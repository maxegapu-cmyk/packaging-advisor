# 要求出参考图时：概念图提示词组装规则

使用者可能用的是任意图像模型，因此本文件只是跨模型描述，不依赖某个特定接口。

先锁定不变项：**同一产品形态、相同品牌名或占位符、同一套包装组成**。再明确每路变量：构图、配色、字体、图形表达。

## 组合提示词

> 一张用于内部讨论的**产品包装视觉方向提案板**，不是印刷成品文件。画面清楚展示同一套[产品]的三个物件：①外箱正面，占视觉主要位置；②一个内盒/内袋，放在其右侧或前方；③一本折叠/小册子式说明书封面，摆在下方。采用[方案名]：主背景[HEX]，主文字[HEX]，识别色[HEX]，点缀[HEX]；布局结构[明确的轴线、比例、主标题位置、主图裁切]；字体风格[粗细及情绪]；图像形式[局部摄影/插图/几何图形]；说明书使用与外箱一致的[视觉锚点]，但内页以清晰的步骤图形为主。真实产品外形必须保持，尽量正视角或温和三分之四视角，柔和可读的布光。标注小字“CONCEPT ONLY / 方向示意”。

避免项：

- 不要凭空添加认证标记、产地、功效、参数和不存在的卖点。
- 不要模仿任何真实品牌 Logo、独有插画或某张参考图的逐像素排版。
- 不要无依据添加配件，不要把说明书当海报以致信息不可读。
- 如果生图文字错误明显，应采用占位符后交由排版工具加真实字，而不是声称已准确排出印刷文字。
- 不要一张图里混用三套风格；一张图对应一条路线。

## 有参考图时

在正向指令追加：

> 参考图只作为[留白密度/色块站位/阅读动线/字体情绪]的启发，不复刻品牌标识、特有构图和素材；产品真实形态依据目标产品图。

## 生成后评价（用户选方向）

按顺序只看：外箱 3 秒是否认出品类；第一眼焦点有没有；HEX 是否体现色彩职责；内包装/说明书有没有同一锚点；文字是否误导。下轮只针对失败项修改。
