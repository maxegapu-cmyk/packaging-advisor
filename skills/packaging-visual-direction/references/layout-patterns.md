# 包装与说明书版式模式库（灵感卡，不是刀模）

选择一个**主构图**，最多一个辅助构图，不要堆叠六种招式。一个产品系列可在相同骨架内变化色带或编号。

## 外箱正面：六种骨架

**1. 海报式偏置**
```
┌─────────────────┐
│ 品牌         ○ │
│                 │
│ 产品名           │
│ 产品名   [物图]  │
│                 │
│      型号 / 描述  │
└─────────────────┘
```
适合香氛、家居、美妆、文创；焦点强烈，但商品类目要仍可辨认。

**2. 色带索引**
```
┌──┬──────────────┐
│色│   LOGO      │
│带│  产品名      │
│/ │              │
│型│    产品图     │
│号│             │
└──┴──────────────┘
```
适合电子、五金、工具、可分 SKU 的系列。色带最好是有含义的编码，而非装饰。

**3. 图像画廊**：上 65% 是完整产品或细节图，下 35% 为产品名、系列名与核心信息。适合注重产品外观的商品。图片背景必须服务文本清晰度。

**4. 单字主角**：只用产品类别的一个大字或符号做主视觉，商品名靠近视觉中心。适合高识别品牌与赠礼包装；新品牌谨慎，防止消费者不知道是什么。

**5. 半幅分栏**：左 50% 放品牌+名称，右 50% 放产品局部或特征图。适合套装、功能清晰的零售产品；平衡，容易落地，但易普通，要在字体或摄影上做差异化。

**6. 包装环腰**：外箱不铺复杂图，只让有色宽腰带贯穿正面与侧面。适合礼盒与系列组合；必须先确认有连续面的实际结构。

## 宋式三种骨架（取自宋画装裱、篆刻与宋版书）

对应 `layout` 字段的 `scroll`、`seal`、`symmetric`。适合茶、酒、香、瓷、文房、老字号与高端礼赠；要求品牌名或品名有 1–4 个能入印的汉字。

**7. 立轴 / 手卷（scroll）**
```
┌─────────────────┐
│▓▓▓▓▓▌ ▓▓▌ ▓▓▓▓▓│  天头（主色）＋两条惊燕
│ ┌─────────────┐ │
│ │       品  明 │ │  画心：竖排题款（题字体）
│ │       名  细 │ │  旁书小字，题款下钤白文印
│ │  ～远山～ [印]│ │  远山：主色为青绿时用青绿，否则用墨色
│ └─────────────┘ │
│▓▓▓净含量▓▓▓▓▓▓▓│  地头（主色）
└─────────────────┘
```
横幅（宽 > 高）改作手卷：右侧引首题款，左侧画心远山，两端为卷首色。留白多、字少，远看要靠题款与印定位品类。

**8. 一方大印（seal）**：品牌刻成一方白文大印压在右上（横幅在左），品名用厚重宋体落在对角；印色取色板里的红（朱砂），没有红就用主色。印章是全盒的锚点：盒顶、罐盖、侧面都只钤这一方印。

**9. 宋版书封面（symmetric）**：中轴对称——文武边栏（外粗内细双线）、四角回纹、品牌小字居中在上、品名写在中轴的题签里竖排、下方居中一枚朱文小印。横幅改为品名横排居中，两侧细线收于菱形。端正、可信，适合送礼与长辈。

宋式骨架里的印章只刻品牌或品名本身，不自造"珍藏""御用""贡品"等字样。

题字（立轴题款、封面题签、宋锦盒题签）用「题字体」：部署方购买了瘦金体商用授权时是瘦金体（宋徽宗为藏画写题签所用之体），否则是开源的朱雀仿宋。写方案时不要承诺"瘦金体"，说"题字体"或"仿宋题签"即可。

## 外箱背面/侧面：四种信息排法

- **编号清单**：01 / 02 / 03 对应产品包含物、使用步骤、注意事项（真实内容由用户填）。
- **图标功能带**：三个并列图标概括特性；须由真实功能支持。
- **窄栏索引**：侧面用竖排品类、型号、系列色，远处也可定位。
- **模块分区**：产品介绍/包装清单/基本信息/警示信息分别区分，避免营销文案和法规信息混作一个区块。

占位字段：`[品牌LOGO] [产品名] [型号] [实际卖点] [条码区] [法规信息] [警示]`，绝不自造认证或功效。

## 内盒/内袋/小包装：四种缩小法

- **留锚点、减内容**：外盒的色带或印章保留，外面 6 个元素内袋仅保留 2 个。
- **分件编号**：多个配件只用相同大小的 01/02/03 + 小标题，方便开箱和回收。
- **抽屉式发现**：包装开启后第一个内表面出现欢迎短句或图形，仍需真实包装结构支持。
- **重复底纹**：外箱主图形缩为低密度重复纹，内袋在主色底上只留品牌名；忌大面积密纹造成脏乱。

## 说明书：四种阅读逻辑

- **一步一步型（推荐多数消费电子）**：封面 → 开箱清单 → 使用前注意 → 编号步骤 → 常见问题/联系信息；每步有图示占位。
- **一页速查型**：一页打开就知道三步怎么启动；复杂合规信息另页。适合易用设备。
- **折页地图型**：从左到右依使用顺序展开；要求确认实际装订或折页方式才细化。
- **模块图鉴型**：按零件、颜色或模块分章节；适合多配件、分体产品。

说明书的阅读优先级高于造型。警示文字必须显著，步骤不能被装饰阻断；不要在看不见原始说明的情况下改写安全操作。

## 全套统一的三种办法

1. **结构锚点**：统一左侧窄色带 / 一根对角线 / 半圆切口。
2. **节奏锚点**：外箱和说明书均使用同一“粗主标题 + 小号次标题”节奏。
3. **编号锚点**：外箱侧面的01型号码，内包装袋子的02配件号，说明书03步骤号用统一字式。

对同一组图，一定说明“哪两个地方保持一致，哪一处允许变体”。
