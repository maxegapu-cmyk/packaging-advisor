# natural-writer · 自然写作助手

一个中文写作 skill,帮你写出**好读、像真人写、传得开**的内容,包括文章、帖子、口播稿和文案。

## 它会做什么

- **先问清楚再动笔**:写给谁、想达到什么效果、手上有什么素材、发在哪里。缺什么只问什么。
- **定中心、选角度、选结构**:先用一句话说清这篇讲什么,再看题目够不够大、够不够新,从六种常用结构里推荐一种。
- **标题和开头**:七种标题写法、五种开头起法。每次给五到八个备选,推荐一个,而且标题说的正文一定兑现。
- **让人读下去,也想转出去**:中段怎么保持新鲜感,结尾怎么收,让人想转发的六个理由,不同形式各自怎么写。
- **三遍自查,外加打分**:内容、传播、语言各查一遍,再从五个维度打分,哪项最弱先改哪项。
- **中文 AI 腔对照表**:从用词、句式、段落、口吻、格式五个层面找出 AI 腔,每条都附改法。
- **不替你编**:缺的数据、例子、经历都会标成待补,一条条列给你。
- **写作手艺和文体**:怎么把抽象写具体、怎么挑例子、句子和段落怎么处理、改稿按什么顺序;六种常见文体各有要点和最容易翻车的地方。
- **完整示范**:从提需求到交稿,示范每一步做到什么程度。
- **跟着你的口气走**:给它一段你自己写的文字,它会按你的习惯来写。

## 安装

把整个 `natural-writer` 文件夹放进 skills 目录。在 Claude Code 里,这个目录是 `~/.claude/skills/`;其他支持 Agent Skills 的工具,放进它们各自的 skills 目录。

## 怎么用

直接说你要写什么,比如:
- "帮我写一篇新咖啡店开业的文章,发朋友圈,500 字左右"
- "我想写周末徒步,怎么写才更容易火?"
- "给这篇文章起几个标题"(附上文章)
- "这段读起来很像 AI 写的,帮我改自然一点"(附上原文)
