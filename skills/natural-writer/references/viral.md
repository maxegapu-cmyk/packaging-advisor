# 让内容传得开

内容是根本,包装决定有多少人愿意了解它。下面按写作顺序排列。

## 一、选题:先过两关

1. **够大**:很多人关心、正在经历,或者正在讨论。
2. **够新**:你的角度、信息或经历,是别人没说过的。同一个题目已经被写烂了,就先想清楚你和别人到底差在哪,能不能用一句话说出来。

**一句话测试**:用一句话把这个题目讲给朋友听,他会不会追着问"然后呢""真的假的"?不会的话,换个角度再试。

## 二、标题:七种常用写法

| 写法 | 例子 |
| --- | --- |
| 真实的具体数字 | 记账一整年,我发现钱都漏在这几个地方 |
| 反常识 | 越节食越容易胖,问题出在早餐上 |
| 点名人群和痛点 | 刚工作的人,第一份工资先别急着存 |
| 结果加过程 | 从月光到存下第一笔钱,我只改了一个习惯 |
| 提问 | 为什么你收藏的教程,从来都没打开过? |
| 对比 | 同样跑步三个月,他瘦了十五斤,我还胖了两斤 |
| 场景 | 凌晨两点还在改方案的人,可以看看这篇 |

**标题的规矩**
- 正文兑现不了的话,不写进标题。读者被骗一次,就不会再点你。
- 数字必须是真的,不要为了好看去凑。
- 少用"震惊""必看""绝了"这类词,读者早就看腻了。
- 每次写五到八个备选,至少换三种写法,最后挑一个最具体的。

## 三、开头:五种起法

1. **场景切入**:直接给一个具体时刻。"上周三晚上十点,我第三次删掉了那份简历。"
2. **反常识**:先抛出一个跟常识相反、但站得住脚的事实。
3. **先给结果**:"这个方法让我每天多出一小时,做法只有一步。"
4. **说出读者正在想的问题**:"你是不是也觉得,越努力越累?"
5. **摆出冲突**:两种说法、两种选择、两个人之间的矛盾。

不管用哪种起法,头几句之内都要让读者知道:读下去能得到什么。

## 四、中段:让人一直读下去

- **每隔几段给点新东西**:一个新例子、一个新数字、一个小转折,或者一个新问题。
- **先抛问题,再给答案**:让读者带着疑问往下读。
- **故事和例子比道理好使**:讲道理之前,先讲一个具体的人和事。
- **数字要换算成读者能感受到的**:"一年省三千块",不如说"相当于每个月多吃两顿火锅"。
- **照顾手机阅读**:段落短,一段只讲一个意思,关键句单独成段。

## 五、让人想转发的六个理由

写完问自己:这篇至少占了其中一两个吗?一个都没有,就补一个。

1. **有用**:读者能直接拿去用,比如方法、清单、避坑指南。
2. **说出心里话**:读者早就这么想,只是一直没说出来。
3. **转了有面子**:转出去显得自己懂行、有眼光、有态度。
4. **情绪够强**:好笑、感动、惊讶、气愤都行,但必须是真的,不要煽。
5. **有一句好记的话**:说得准、记得住。
6. **有故事**:有具体的人,发生了具体的事。

## 六、结尾:三种收法

- **一句能带走的话**:简短、准确,读完还记得。
- **一个具体行动**:"今晚睡前试一次就知道。"
- **一个读者真心想回答的问题**:要能引出真实讨论,不是生硬地求点赞。

## 七、不同形式,写法不同

| 形式 | 要点 |
| --- | --- |
| 图文长文 | 小标题方便读者扫读;开头三行决定读者留不留下 |
| 短帖 | 第一句就是全部;一帖只讲一个点 |
| 口播稿、视频稿 | 写给耳朵听:句子短,少用书面词,数字要少而好记,关键的话说两遍 |

## 八、常见的坑

- **标题党**:标题许下的,正文没兑现。
- **注水**:写满一千字,有用的只有三句。
- **情绪过头**:读者觉得被操纵,会直接关掉。
- **说教**:一直告诉读者"应该怎样",却不给事实和理由。
- **硬蹭热点**:热点和正文没有真正的关系。
