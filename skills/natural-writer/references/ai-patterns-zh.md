# 中文 AI 腔对照表

AI 写中文,最常露馅的是五个层面:用词、句式、段落、口吻、格式。

**怎么用**:先通读全文,把命中的地方标出来,再从最刺眼的那处改起。一处可疑,不一定就是 AI 腔;好几处扎堆出现,才需要动手。有时候整段重写,比一句一句修更自然。

## 一、用词

| 毛病 | 常见样子 | 改法 |
| --- | --- | --- |
| 套话高频词 | 赋能、助力、深耕、全方位、多维度、闭环、抓手、底层逻辑 | 换成具体做了什么;没内容就删 |
| 空洞拔高 | 里程碑式、开启新篇章、意义深远、不可或缺、至关重要 | 说清具体影响了谁、改变了什么 |
| 万能动词 | 进行了优化、实现了提升、打造了平台、起到了作用 | 直接说"改了""快了一倍""做了一个" |
| 翻译腔 | 作为一个……、对于……来说、被……所……、使得 | 按中文口语的顺序重新说一遍 |
| 成语堆砌 | 一句话里塞好几个四字词 | 留一个最准的,其余拆成白话 |

## 二、句式

| 毛病 | 常见样子 | 改法 |
| --- | --- | --- |
| 先否定再肯定 | "这不是……,而是……"(并没有人说过"是……") | 直接说"是什么" |
| 排比凑数 | 硬凑成三个、四个,其中有一两个是凑的 | 实际有几个就写几个 |
| 段尾升华 | 每段最后一句都是感悟或总结 | 删掉;要升华,全文留一处就够 |
| 设问太多 | "那么问题来了……""为什么呢?因为……" | 一篇最多一两处,其余直接说 |
| 机械连接 | 首先、其次、再次、最后;值得一提的是 | 用内容本身的逻辑去衔接 |
| 句子一样长 | 每句长短差不多,读起来像念经 | 长短句交替,中间穿插几句短的 |
| 符号滥用 | 破折号、冒号、感叹号到处都是 | 留下必要的,其余改成逗号或句号 |

## 三、段落

| 毛病 | 常见样子 | 改法 |
| --- | --- | --- |
| 段段等长 | 每段三四行,长得一模一样 | 重点段写长,过渡段写短 |
| 模板化分点 | 每节都是"小标题+三个要点" | 短文改回连贯的叙述 |
| 开头复述题目 | 第一句把标题换个说法再讲一遍 | 直接从第二句开始写 |
| 结尾重复全文 | "总而言之……"再总结一遍 | 换成一个行动建议,或者一个具体画面 |
| 只有道理 | 一整段没有一个例子、数字或细节 | 补一个具体的;补不出来就删 |

## 四、口吻

| 毛病 | 常见样子 | 改法 |
| --- | --- | --- |
| 客服腔 | 好的!以下是……;希望对你有帮助 | 全部删掉 |
| 过度谨慎 | 可能、在一定程度上、或许、某种意义上 | 有把握就直接说;没把握就说清哪里没把握 |
| 无名权威 | 研究表明、专家指出、业内普遍认为 | 给出出处;给不出就删掉 |
| 推销腔 | 极致体验、匠心打造、不容错过 | 换成具体的事实和感受 |
| 说教腔 | 我们要……、每个人都应该…… | 讲清事实和后果,让读者自己判断 |

## 五、格式

| 毛病 | 常见样子 | 改法 |
| --- | --- | --- |
| 乱加粗 | 每行都有加粗的字 | 全文只加粗最关键的一两处 |
| 标题装饰 | 表情符号、箭头、每节都有分隔线 | 去掉装饰;短文连小标题也可以不要 |
| 列表成瘾 | 本该成段的话被拆成一条条 | 有前后因果的内容写成段落 |

## 改完念一遍

在心里把全文念一遍,念着别扭、像在背课文的地方再改一次。最后核两件事:有没有加进原来没有的事实,有没有丢掉原来的意思。

## 不要动的地方

引文、专有名词、作者故意保留的口头禅和方言,还有那些只有真人才写得出的细节,比如具体的时间地点、矛盾的心情、跑题的小插曲,都保持原样。这些正是文字像人写的原因。
