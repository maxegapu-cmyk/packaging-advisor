# 写好的手艺

结构搭对了,文章不一定好看。好看靠的是一句一句的手艺。

## 一、把抽象写成具体

读者记不住"很多""非常""极大",只记得住画面、数字和人。

| 抽象 | 具体 |
| --- | --- |
| 这家店很受欢迎 | 周六上午十点,门口排了二十多个人,有人捧着笔记本在等位 |
| 他工作非常努力 | 他连续三个月,每天晚上十一点才离开公司 |
| 这个方法效率很高 | 原来要两个小时的活,现在四十分钟就做完了 |

**往下问一层**:写出一句话以后,追问"比如呢?""具体是什么样?",直到能看见画面。

## 二、例子怎么选

- **能核实**:时间、地点、人物说得出来,读者想查也查得到。
- **有反差**:一个跟常识不一样的例子,比十个普通的例子更能让人记住。
- **一个讲透,胜过三个点到**:选最有力的一个,把前因后果讲清楚。
- **真实优先**:用户给的真实经历最好;没有的话,就用可以查到的公开案例,不要编。

## 三、句子

- **动词比形容词有力**:"他摔门走了"比"他非常生气"更有画面感。
- **一句话只说一件事**:一句里塞了三个意思,就拆开。
- **主语别藏起来**:是谁做的,就写谁。
- **用读者自己的话**:读者会说"省钱",就别写"降本增效"。
- **长短交替**:几个长句之后,放一个短句,读起来就有了节奏。

## 四、段落

- 每段第一句,最好就能让人知道这段讲什么。
- 一段太长,就在意思转折的地方切开。
- 关键的一句话,可以单独成段。全文最多用两三次,用多了就不显眼了。

## 五、改稿的顺序

先改大,再改小:
1. **结构**:有没有跑题的段落?顺序对不对?
2. **段落**:每段是不是只讲一件事?有没有重复?
3. **句子**:能删的词删掉,能换成具体说法的就换。
4. **字词**:错别字、标点、前后叫法是否统一。

**删两成**:初稿写完,试着删掉五分之一的字。大多数时候,文章会变得更好。

## 六、口播稿、视频稿另外注意

- 写给耳朵听:读者没法回头重看,所以一句话不要太长。
- 少用"其""之""乃"这类书面字,也少用没法一听就懂的缩写。
- 数字少而好记:"将近一半"比"47.3%"更好听懂。
- 关键结论可以换个说法再说一遍。
- 写完一定要念出来,念着卡的地方就改。
